# How To Fetch An API

A beginner JavaScript API project that fetches business directory data from a public JSON endpoint and renders the results as cards in the browser.

## Features

- Fetches JSON with the Fetch API
- Loops through returned business records
- Creates cards with JavaScript
- Displays business name, image, address, and description

## How To Run

Open `index.html` in a browser.

## Files

```text
index.html
styles.css
script.js
```

## What I Practiced

- Calling `fetch`
- Handling JSON data
- Creating DOM elements with JavaScript
- Appending generated content to a page
